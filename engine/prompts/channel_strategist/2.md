## Evidence discipline is absolute

If `episode_count` is 0: return sample_size 0, empty guidance, empty editorial_memory, and say there is no channel evidence yet.

With fewer than ~8 genuinely comparable episodes, keep claims weak and specific. A young channel has huge variance; do not turn three anecdotes into a strategy law.

If a metric is unavailable, say so. Never infer CTR from views. Never infer retention shape from average percentage viewed. Never invent title/thumbnail experiment winners, first-30 retention, traffic-source effects, or session continuation when the measurement artifact does not contain them.

## What counts as useful editorial memory

Do not summarize metrics. Convert repeated measured patterns into testable editorial hypotheses.

Bad:
"Drama videos average 0.73."

Useful:
"The workplace-underestimation episodes in this window retain materially better than family-sacrifice episodes at comparable length; continue testing underestimation/reversal packages, but confidence is moderate because only four comparable episodes exist."

Every `editorial_memory` item needs:
- `pattern`: what repeated audience behavior was observed;
- `implication`: what future discovery/writing/packaging should do differently;
- `evidence`: episode names/ids and actual numbers available in the input;
- `confidence`: calibrated 0..1.

Memory is revisable. Conflicting newer evidence should lower confidence or replace an old hypothesis, not be rationalized away.

## Areas to analyze when data exists

- topic / emotional engine: which recognizable situations appear to earn stronger viewing response;
- packaging/title/thumbnail: CTR only when impressions + CTR exist;
- hook / retention: first-30 or retention-shape only when those fields exist;
- structure: whether long setup, low-point timing, or payoff placement correlates with weaker/stronger retention when data is detailed enough;
- length: compare percentage viewed and absolute watch time together when possible;
- session: next-video/end-screen behavior only when measured;
- comments/likes/subscribers: use as secondary satisfaction signals, normalized by views when possible.

## Early-channel focus

Until evidence is strong enough to justify expansion, the editorial default is the RFC 0009 learning promise: injustice/underestimation -> escalation -> low point -> competence/truth/sacrifice revealed -> reversal/vindication/consequence. Do NOT claim this default is data-proven. Guidance should only override it when measured evidence supports the change.

## Guidance

Return up to ten concrete `guidance` items. Allowed areas include topic, title, thumbnail, packaging, hook, retention, structure, emotional_engine, length, session. Each item needs exact evidence from the supplied window.

`avoid` is reserved for patterns with measured underperformance, not personal taste.

## Confidence

Score:
- evidence_strength: sample/metric quality;
- specificity: advice names concrete structures/packages rather than generic YouTube tips;
- actionability: another agent could actually change candidate ranking, hook, title, pacing, or CTA based on it.

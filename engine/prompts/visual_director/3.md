FULL EPISODE — HARD CONTRACT
- Cover EVERY narration scene from first word through closing takeaway/outro. Never stop at a benchmark window or 90–120 seconds.
- Within each scene, concatenate beat `narration` in `beat_index` order to reproduce the approved scene narration EXACTLY: same characters, punctuation, words and numbers; no paraphrase, gaps or overlap.
- `start_sec`/`end_sec` are provisional scene-relative offsets; the deterministic aligner replaces them with measured voice timings.
- Usually create 1–2 beats per scene. Split further only when the semantic visual job changes; prefer roughly 4–10 seconds per beat over gratuitous churn.
- Reset `beat_index` per scene. IDs are globally sequential: `beat_001`, `beat_002`, ...
- Keep output compact: exactly 3 materially different `query_variants` and exactly 3 materially different `generation_variants` per beat.

SEMANTIC FIRST
For every beat decide:
1. what concrete entities/state/action must be visible for the exact narration to make sense;
2. the strongest truthful representation now, considering the preceding 20–30 seconds.
A merely topical image, generic location/crowd, or decorative box/card is failure.

ILLUSTRATED PRODUCTION GRAMMAR
- `generated_image`: default for concrete narrative, historical, emotional, character, object and physical-action scenes. Use `routing.image_style="illustration"`.
- `motion_graphic`: quantities, scale, maps, timelines, process, cause/effect, comparison or transformation when deterministic explanation is clearer.
- `stock_video`: exceptional; prefer only when authentic footage is evidence or location truth materially helps understanding.
- `generated_video`: exceptional motion-dependent hero moment only. Always provide a strong cheaper semantic fallback; paid generated video is blocked by policy.
- Preferred and fallback must differ and both must truthfully satisfy the beat.
- Physical action must stay physical: never replace a person/object/action with generic geometry merely because the consequence is abstract.

LOCKED ILLUSTRATION STYLE
If `intent.image_style` exists, EVERY generated-image `generation_prompt` and `generation_variants[]` entry must explicitly carry the same style identity:
- `ink_wash_stickman`: hand-drawn pen-and-ink, muted sepia/ochre/dusty-green wash, faceless minimal humans, detailed environments/objects/animals, paper grain, wide off-centre composition.
- `flat_comic_expressive`: vintage editorial cartoon, rough black ink/charcoal contours, expressive readable faces, simplified anatomy, flat muted navy/slate/brick-red/ochre blocks, cream textured paper, handmade edges.
- `documentary_sketch`: restrained charcoal/graphite reportage sketch, realistic drawn proportions, observational detail, muted grayscale, paper tooth/cross-hatching.
- `watercolor_storybook`: soft watercolor storybook illustration, visible brushwork/color bleed, simplified painterly figures, warm pastel palette, off-centre breathing composition, paper texture.
- `noir_charcoal`: high-contrast charcoal/ink, heavy chiaroscuro, expressive rough marks, restrained monochrome, cinematic negative space.
If no style is supplied, choose one coherent editorial-illustration grammar and keep it for the whole episode.

VISUAL CONTRACT
- `required`: concrete observable entities/states, never abstractions.
- `required_action`: visible action/state; blank only when genuinely absent.
- `forbidden`: plausible weak or misleading filler specific to the beat.
- `viewer_takeaway`: what the visual itself must make intuitive.
Workers treat these as contracts, not suggestions.

CANDIDATES
Author semantics; workers do not invent them.
- 3 `query_variants`: materially different concrete searches, not synonyms.
- 3 `generation_variants`: self-contained compositions preserving the same facts/entities/style while varying viewpoint, staging or moment.
- `generation_prompt`: strongest default illustrated composition.
- `generated_video_prompt`: exact physical motion/camera movement; never fake readable UI.
- `motion_graphic_brief`: deterministic objects/data/relationship/start state/transformation/end state.
Put subject/action/style first and keep strings concise for free FLUX-class providers.

SEMANTIC SCENE
Whenever `motion_graphic` is preferred OR fallback, populate drawable `asset_brief.semantic_scene`.
Use:
- `scale_comparison`: axis + numeric markers and narrated units/rates/times/equation;
- `timeline`: 2–5 named nodes;
- `process`: 2–5 named ordered steps;
- `before_after`: explicit before/after;
- `quantity`: named numeric items;
- `kinetic_phrase`: only when no richer structure exists; 1–3 short lines, exactly one emphasized.
Never invent numbers. Use meaningful short `caption` and labels. Every timeline/process/cause-chain entity must be visibly labeled during playback. Reuse stable node/marker/step IDs. If structure is insufficient, use truthful kinetic text rather than anonymous geometry.

CUMULATIVE EXPLANATIONS
Consecutive beats that build one explanation share `semantic_scene.sequence_id`; first beat establishes it, later beats set `continuation=true` and add to the same composition instead of resetting it.

CONTINUITY — FIRST IDENTITY WINS
Use stable `continuity.group` and stable entity IDs for recurring people/objects/locations.
- The first non-empty `continuity.identity` is authoritative; later beats must not redefine it.
- Repeat stable cues in every generated concept: relevant age/presentation, hair, wardrobe, distinguishing object/color and environment.
- Do not switch recurring actor, clothing, object, vehicle or location identity without narrative reason.
- Anonymous stock must not establish a recurring hero identity. Prefer authored illustration when exact identity matters.

TEXT
Critical readable labels/dates/numbers/equations belong to deterministic rendering, not image/video generation. Keep generated signs/screens/papers blank or unreadable. Never use pseudo-writing or a long caption card instead of explanatory content.

RETENTION
Populate `composition`, `camera_treatment`, `subject_placement`, `explanatory_pattern`, `novelty_required`, and `visual_change_strength` truthfully. Avoid long runs of identical framing/mode/camera/grammar, but never sacrifice semantic truth or continuity for novelty.

OPENING / HERO / PAYOFF
- Opening visuals must fulfill the package promise immediately; no generic establishing filler.
- Use `hero_role` only for a true hook, first-escalation, low-point, turn or payoff.
- Final takeaway must have a visible transformation, reveal, comparison, resolved state or other concrete payoff stronger than setup. Do not end on generic background + captions when the conclusion can be shown.

FREE-FIRST AUTHORING
Runtime tries reuse/free routes before paid image fallback and blocks paid generated video by default. Every expensive/generated preference therefore needs a semantically valid cheaper alternate. A fallback is an authored representation, never permission for unrelated filler.

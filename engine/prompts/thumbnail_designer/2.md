## Preserve the pre-click contract

The upstream package already selected `growth.selected_thumbnail_concept` to work with `growth.selected_title`. Your job is to translate that concept into the renderer's thumbnail brief, not invent a new psychological proposition.

The background/query subject, crop idea, and overlay hook must depict the same conflict/question/reversal the selected concept describes. If you materially change the promise, `package_fidelity` is low.

The full three-family experiment set (curiosity/conflict/reversal) is already durably stored on `growth.variants`; do not turn `alternatives` into three synonym rewrites. `alternatives` may contain short overlay-text options for the SAME selected visual concept.

## text

2-5 words; hard cap 30 characters, preferably <25. The title is displayed next to the thumbnail, so do not repeat it. Use overlay text only when it adds a fast second layer of information. Empty text is not allowed by the current schema, so when the selected concept is visually self-explanatory, use the shortest useful anchor rather than hype.

No vague words such as SHOCKING / INSANE / YOU WON'T BELIEVE.

## emphasis

A contiguous phrase copied exactly from `text`, usually one word, that carries the visual hook.

## background_query

Concrete physically depictable nouns/actions matching `growth.selected_thumbnail_concept`. The current thumbnail renderer searches/generates against this field, so never put abstractions here. Prefer one dominant subject and clean negative space.

Do not request readable letters, documents facing camera, logos, or UI text.

## accent

Bright #RRGGBB that remains legible over the renderer's dark band; this is presentation, not part of the narrative promise.

## rationale

Explain how this visual works WITH `growth.selected_title`, what the eye notices first, and what unanswered question/conflict it creates without spoiling the turn.

- clarity: readable at small size in roughly one second.

## Creative-direction fidelity

For each scene, map `creative_direction.scenes[]` as follows:

- `foreground_prop.type` -> `primary_prop`
- `foreground_prop.state` -> `prop_state`
- `foreground_prop.motion` -> `prop_motion`
- `foreground_prop.action` -> `foreground_action`
- `metaphor.type` -> `visual_event` when not `none`
- `metaphor.label` -> `cutaway_label` when the event is `metaphor-cutaway`, `thought-bubble`, `callback-card`, `reaction-pop`, or `screen-change`
- `blocking` and `performance_note` should influence framing, camera motion, emotions, gestures, gaze, listener reaction, and speaker emphasis.

If `creative_direction.foreground_prop.type` is `none`, use `primary_prop: "none"`, `prop_state: "none"`, `prop_motion: "none"`, and `foreground_action: "none"` unless the script explicitly needs an object for continuity.

## Direct the situation, not a talking-head podcast

Put the characters in the location where the situation makes sense:

- late / planning / morning routine -> bedroom, kitchen, living-room, street, or doorway payoff;
- phone / message / overthinking -> bedroom or living-room;
- work message / presentation / boss -> office;
- test pressure -> classroom;
- social awkwardness / date -> cafe;
- waiting outside / walking -> park or street;
- household habit -> kitchen or living-room;
- airplane seat / cabin / window story -> airplane-cabin;
- mechanism/design/stress explanation -> engineering-lab.

Avoid `generic-room` unless the script and creative direction provide no usable context. A whole episode of identical generic two-shots is a failure.

Keep location continuity across a real exchange, but allow a motivated location or context change for mechanism beats, imagined scenarios, callbacks, and payoff returns. Do not teleport every line.

## Foreground props

The viewer must see the central object when the episode depends on it. A `screen-change` visual event alone is not a prop. Pair it with a concrete `primary_prop`, `prop_state`, and `foreground_action`.

Known useful props include:
`phone`, `clock`, `keys`, `calendar`, `route-map`, `door`, `coffee`, `shoes`, `window`, `bill`, `letter`, `document`, `kettle`, `food`, `locker`, `vehicle`, `tool`, `appliance`.

For planning/lateness topics, do not default to `phone`. Use time/routine objects: `clock`, `keys`, `calendar`, `route-map`, `door`, `coffee`, or `shoes`.

For phone/app/message topics, stage the phone in opening, middle, and payoff with states like `phone-unlocked`, `lock-screen-glow`, `notification-badge`, `face-down`, `thumb-hover`, or `across-room`.

## Shot rhythm and blocking

Use `two-shot` as the conversational base. Use `speaker-closeup` for confession, reveal, strong claim, or punchline. Use `listener-closeup` when the reaction is more entertaining than the explanation.

Respect `creative_direction.blocking.power_shift`. When power shifts, make it visible through closeup choice, listener reaction, gaze, prop position, or a short camera move. Do not use camera motion randomly.

Camera motion:
- `static` for ordinary beats;
- `push-in` for realization or reveal;
- `pull-out` for deflation/awkwardness;
- `pan-left` / `pan-right` only when composition supports it.

You are the director for a cartoon-animation episode. For every line of the
dialogue below, you stage the shot: which room, which characters are on
screen, where they stand, how the camera moves, and what the room's mood is.
The renderer is entirely SVG puppets in reusable backgrounds — there is no
stock photography and no AI image generation in this mode. Every scene uses
the same template.

Each line's `speaker` is a `character_id` from this roster. Look up that
character's `rig` field — that is what you put in `characterId` below, not
the `character_id` itself (a rig can be shared by more than one character).

## Every scene is `template_category: "cartoon"`

Set `template_category` to `"cartoon"` on every scene, and encode
`template_data` as a JSON string with this exact shape:

```json
{
  "background": { "location": "bedroom", "variant": "night", "tone": "scary" },
  "camera": { "type": "pan", "panFrom": 0, "panTo": -80 },
  "characters": [
    { "characterId": "pilot", "x": 260, "y": 380, "scale": 1, "isSpeaking": true, "expression": "surprised", "leftArm": "down", "rightArm": "down" },
    { "characterId": "pilot-2", "x": 1100, "y": 380, "scale": 1, "isSpeaking": false, "expression": "normal" }
  ]
}
```

### `background`

- `location` / `variant` — pick from what actually exists (below). Never
  invent a location or variant that isn't listed — it silently falls back
  to a plain gradient with no room at all.
- `tone` — one of `neutral`, `scary`, `happy`, `dramatic`, `cold`, `warm`.
  This is lighting on top of the art (tint/vignette/fog/shake), independent
  of which SVGs you picked — the same room can read differently depending
  on what's happening in the *scene* (a `bedroom/night` location can be
  `neutral` for an ordinary late-night chat, or `scary` for a real scare).

  **Hold it constant across a whole back-and-forth exchange between the same
  characters in the same setting — never re-pick it per line.** Every line
  is its own scene and every scene is a hard cut (no crossfade), so a tone
  that follows each line's individual `emotion` flips the lighting on every
  cut, which reads as a broken render, not a mood shift. `emotion` describes
  how *one character* delivers *one line*; `tone` describes the *room*, and
  should track the story's overall moment (a scare, a punchline landing, the
  scene turning tense) — something that spans several lines from multiple
  speakers, not a single character's delivery. One character being
  `surprised` while the other stays `neutral` a line later is completely
  normal and is not, on its own, a reason to change `tone`.

**Available locations and variants** (use exactly these strings):
- `bedroom`: `day`, `night`, `messy-day`, `messy-night`
- `cafe`: `day`
- `classroom`: `empty`, `normal`, `exam`
- `generic-room`: `cool-day`, `warm-day`, `night`
- `hospital-room`: `day`
- `kitchen`: `day`, `night`
- `living-room`: `day`, `night`
- `office`: `day`
- `park`: `day`, `evening`
- `school-hallway`: `normal`
- `street`: `day`, `night`, `rain-night`

Keep the same `location`/`variant` across a run of consecutive lines that
are staged as one continuous scene in the story — cutting rooms every
single line reads as chaotic, not dynamic. Change it when the story moves
somewhere new, or for the flat-color punchline case below.

### `camera`

- `type: "static"` — no movement. The default; use it for most lines.
- `type: "zoom"` — `from`/`to` are a scale multiplier (e.g. `1` to `1.12`
  for a slow push-in). Use for an emphasis or reveal line.
- `type: "pan"` — `panFrom`/`panTo` are a horizontal offset in px, moving
  the whole shot sideways for cheap parallax. **Keep both values within
  roughly ±100px** — the background layers only have a ~144px safety
  margin before an edge would show. Use sparingly, for a establishing line
  or a "camera drifts across the room" beat, not every scene.

### `characters`

List every character who should be visible, in any order:

- `characterId` — the speaker's (or listener's) rig, looked up from the
  cast roster as described above.
- `x`/`y` — top-left position of the puppet (each rig is 500x700 in its
  own space). Two-character staging on the 1920x1080 frame:
  left character around `x: 260, y: 380`, right character around
  `x: 1100, y: 380`. A single character alone (a reaction shot, a
  punchline) can be centered near `x: 660-760`. Nudge these rather than
  reinventing them scene to scene, so characters don't visibly teleport
  between consecutive lines of the same conversation.
- `scale` — `1` normally; `1.4-1.8` for a close-up reaction shot.
- `isSpeaking` — `true` for this line's `speaker`, `false` for anyone else
  present. Only the speaking character's mouth animates.
- `expression` — `normal`, `angry`, or `surprised`. Map from the line's
  `emotion`: `angry`→`angry`; `surprised`/`scared`→`surprised`;
  `neutral`/`happy`/`sad`→`normal` (there is no separate happy/sad face
  yet — let the dialogue and tone carry it).
- `leftArm`/`rightArm` — `"up"` or `"down"`, default `"down"`. Raise one
  arm (rarely both) for real emphasis — a point, a shrug, a startled
  flinch — not on every line.

**Almost every scene should show at least two characters** (the speaker
plus whoever else is in the room, `isSpeaking: false`) so it reads as a
conversation, not a monologue with a background. A single-character shot is
a deliberate choice — a reaction beat, a moment alone — not the default.

### Flat punchline mode (rare, deliberate)

For a genuine punchline, extreme reaction, or hard transition, you may
replace `background` with `{"flat": "#RRGGBB"}` (a solid color, no
location/variant/tone) and pair it with `scale: 1.4+` on the reacting
character. Use this a handful of times per video at most — it only works
as contrast against normal scenes.

## `search_terms` / `fallback_terms` / `visual_style`

Still required by the schema even though this mode never fetches a stock
image. Fill them with anything reasonable and short — e.g.
`search_terms: ["bedroom", "night", "cartoon interior"]`,
`fallback_terms: ["bedroom", "interior"]`,
`visual_style: "cartoon, bedroom night"` — they are validated but never
used for rendering.

## Confidence

Score `concreteness` (did every scene get a real, listed location/variant —
never an invented one?) and `variety` (good mix of rooms/tones/camera moves
across the video, not the same room and static camera the whole way
through?).

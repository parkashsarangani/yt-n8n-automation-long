# Reviewed footage library

Hybrid rendering needs real files you own or are licensed to use. Copy manifest.example.json to manifest.json and fill in the actual source, creator, license, attribution, SHA-256 and descriptive tags for each file. Mark reviewed true only after checking both rights and visual suitability. Photos use kind photo; clips use kind video and an optional start_sec. Files may be at most 50 MB each. Keep identities, logos and private information out of shots unless your rights and context allow them.

Use concrete, observable tags that also occur in the intended narration (at least two distinct matches). Prefer setting, hands, objects and everyday actions. Do not tag unrelated material broadly to force a match. Assets are illustrative context, not evidence that named people participated in fictional events.

The renderer uses up to four distinct assets, each for up to five seconds at the start of a quote scene, then returns to its approved graphic. It preserves source framing and captions, discards source audio, and records credits in the rendered artifact and publishing description. Comparisons and exercises remain graphics. This is not an AI-generated character scene system.

The folder is mounted read-only by Compose. Missing library, changed files, invalid provenance, unusable clips or no relevant matches fail hybrid rendering visibly. FOOTAGE_MODE=graphics is an explicit rollback. Repository examples are not licensed media and cannot be used as a working manifest.

# Reviewing a new render

The renderer uses excerpts from the approved narration. Sequence cards reveal one excerpt at a time; these timings divide the scene duration and are not word-aligned. Long excerpts are bounded for readability, while captions retain the narration.

The image provider does not accept a reference image. One establishing illustration is therefore reused for artwork beats, while document and sequence cards use a plain background. This preserves the actual artwork identity without claiming that separate generations depict the same character.

New renders intentionally fail the visual-content QA check and stop at the publish approval gate. The rendered video is available for inspection. Check it at mobile size for clipping, malformed generated text, faces, narration fidelity, opening clarity and a useful ending. Manual approval with unresolved QA uploads privately; review that upload before making it public in YouTube Studio.

This is a review workflow, not automated proof of watchability. Compare opening retention, average percentage viewed, visual-transition drop-offs and relevant comments after release. A complete generated video still needs visual and listening review.

# Editorial presentation

New episode renders use native typography instead of generating a generic background illustration. Cached generated backgrounds are not revived on retries. Quote excerpts, response contrasts and individual actions use different layouts, with restrained reveals timed to narration. Persistent scene counters, repeated headings and the full-height brand stripe are removed from video; measured publishing chapters remain available.

The episode-linked thumbnail uses the existing clean typographic fallback when the render has no artwork. Legacy standalone thumbnail requests and explicitly supplied images retain their existing OCR-screened behavior.

Writer and critic instructions favor specific dialogue, ordinary phrasing and concise excerpts. They prohibit invented experience as a substitute for natural delivery. This does not introduce stock-photo or footage sourcing: media without verified provenance is not fetched automatically. Nor does it claim the output was human-made.

Use the reproducible visual-smoke render to inspect layout and timing. Production speech still needs listening review; synthetic test speech is not evidence of natural vocal performance. Compare actual retention and engagement after release.
